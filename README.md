# 🔥 Ignitia Core  
### AI-Based Wildfire Prediction and Terrain-Aware Simulation System

---

## 📌 Overview

Ignitia Core is an AI-driven system designed for real-time wildfire risk prediction and dynamic fire spread simulation. The platform integrates machine learning models with terrain-aware simulation logic to estimate fire propagation under varying environmental conditions.

Developed as part of a national-level hackathon project, Ignitia aims to support early warning systems, disaster management teams, and environmental monitoring agencies.

---

## 🎯 Key Features

- 🔥 Wildfire Risk Prediction  
  Predicts fire likelihood using environmental parameters such as temperature, humidity, and wind  

- 🌍 Terrain-Aware Simulation  
  Models fire spread dynamically based on terrain, vegetation, and external conditions  

- ⚡ Real-Time Processing  
  Designed for rapid inference and simulation for time-sensitive applications  

- 📊 Data Output & Visualization  
  Generates structured outputs (CSV) for simulation points and fire spread analysis  

---

## 🧠 System Architecture

Input Data → ML Prediction Model → Simulation Engine → Output Visualization  

Components:  
- ML Module: Fire risk prediction  
- Simulation Engine: Fire propagation modeling  
- Backend (Node.js): Data handling and API logic  
- Visualization Layer: Output interpretation  


---

## ⚙️ Tech Stack

Machine Learning: Python, Scikit-learn  
Backend: Node.js, Express.js  
Data Processing: CSV-based simulation outputs, custom terrain modeling
